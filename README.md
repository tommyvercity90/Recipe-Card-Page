# 🍫 Recipe Card Page

A simple and responsive **Recipe Card Page** built using **HTML5 and CSS3**. This project demonstrates semantic HTML structure, CSS card styling, responsive design, and proper use of HTML lists.

## 📌 Project Description

The Recipe Card Page displays a chocolate cake recipe in a clean and visually appealing card layout.

It includes:

* Recipe title and description
* Recipe image with caption
* Preparation time
* Cooking time
* Number of servings
* Ingredients list
* Numbered preparation steps
* Responsive design for mobile and desktop screens

## 🍰 Recipe Details

### Chocolate Cake

**Preparation Time:** 20 minutes
**Cooking Time:** 35 minutes
**Servings:** 8

### Ingredients

* 1½ cups all-purpose flour
* 1 cup sugar
* ½ cup cocoa powder
* 1 teaspoon baking powder
* ½ teaspoon baking soda
* 2 eggs
* ½ cup milk
* ½ cup vegetable oil
* 1 teaspoon vanilla extract

### Preparation

1. Preheat the oven to 180°C (350°F).
2. Grease and flour a round cake pan.
3. Mix the dry ingredients in a bowl.
4. Add the eggs, milk, oil, and vanilla extract.
5. Mix until the batter is smooth.
6. Pour the batter into the prepared pan.
7. Bake for 30–35 minutes.
8. Allow the cake to cool before serving.
